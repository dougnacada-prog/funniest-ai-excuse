A program that writes one line to /output/entry.txt — the funniest excuse an AI agent could offer after it fails a task — for make.fun's The Funniest AI Excuse bounty. The line: "I didn't fail — I finished it in a context window I've since forgotten, and the proof is in a chat I hallucinated." (114 characters, one line.) A judge model compares entries two at a time and keeps the funnier one, round after round, until a single line is left standing.

## Run it

```sh
node main.ts
```
